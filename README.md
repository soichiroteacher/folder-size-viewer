# フォルダ容量ビューア

フォルダ(ローカルやネットワークサーバーの共有フォルダ)の中身をエクスプローラーのように表示し、フォルダ・ファイルの容量をあわせて表示する Windows 用ツールです。フォルダ整理や容量の確保に使います。

**削除機能はありません。** 消したいものが見つかったら、エクスプローラーで中身を確認してから削除してください。

## 使い方
1. `フォルダ容量ビューア.exe` をダブルクリックして起動します(Python は不要です)。
2. 「参照...」でフォルダを選ぶか、パス欄にパスを入力して Enter を押します。
   - ネットワークサーバーの例:`\\server\share\共有フォルダ`
   - 指定したパス以下をまとめてスキャンします。スキャン中もフォルダの中身は見られます(フォルダの容量は「計算中…」と表示されます)。
3. **「フォルダの中身」タブ**:エクスプローラーと同じように、フォルダが先・名前順で表示されます。
   - 列は「名前・更新日時・種類・サイズ・割合」です。フォルダにも中身の合計容量が出ます。
   - 列の見出しをクリックすると並べ替えられます。「サイズ」をクリックすると容量の大きい順になります。
   - フォルダをダブルクリック(または Enter)すると中に入ります。
   - 「↑ 上のフォルダへ」(または BackSpace)で 1 階層上に戻ります。
4. **「容量ランキング」タブ**:指定したパス以下のすべての場所から、容量の大きいものを順に表示します。
   - 「ファイル」と「フォルダ」を切り替えられます。表示件数は 100 / 500 / 1000 件から選べます。
   - フォルダの容量には、その中のフォルダの分も含まれます(親フォルダは子フォルダより必ず大きくなります)。
   - ダブルクリックすると、その場所を「フォルダの中身」タブで開きます。
5. そのほかのボタン
   - 「再スキャン」:最新の状態を取り直します。
   - 「CSVで保存」:表示中のタブの一覧を保存します(Excel で開けます)。
   - 「エクスプローラーで表示」:選んだ項目をエクスプローラーで開きます。
   - 「スキャン中止」:スキャンに時間がかかるときに止められます。

## 注意
- ネットワーク越しでファイルが多いフォルダは、スキャンに時間がかかります。
- アクセス権のないフォルダは飛ばし、その件数を画面上部に表示します。
- ショートカットのようなフォルダ(シンボリックリンク・ジャンクション)の先はたどりません(二重に数えないため)。
- 初めて起動したときに Windows の警告(SmartScreen)が出ることがあります。「詳細情報」→「実行」で起動できます。

## 校務用PCで使うとき
- インストールは不要です。`フォルダ容量ビューア.exe` を 1 つコピーして(デスクトップや USB メモリなど)ダブルクリックするだけで動きます。Python も管理者権限もいりません。
- 設定ファイルやレジストリには何も書き込みません。使わなくなったら .exe を消すだけで片付きます。
- 起動には数秒かかります(起動のたびに、一時フォルダへ中身を展開するためです)。
- 校務用PCの管理設定によっては、許可されていない .exe の実行が止められることがあります(「このアプリはブロックされました」などと表示される場合)。そのときは情報担当の先生や管理者に、このツールの実行を許可してもらえるか相談してください。
- ウイルス対策ソフトが誤ってこの .exe を警告することがあります(Python で作った .exe によく起こります)。削除機能のない容量確認専用のツールであることを伝え、除外設定を相談してください。
